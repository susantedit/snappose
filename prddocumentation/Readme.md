# 📖 Overview

Snap Pose is an AI-powered mobile application that helps users recreate beautiful poses using augmented camera overlays and real-time pose analysis.

The app combines computer vision, mobile photography, and artificial intelligence to provide a personal photography assistant.

Instead of guessing how to pose, users simply choose a reference pose and align themselves with an on-screen overlay.

Future versions include AI pose coaching, skeleton tracking, automatic capture, lighting analysis, and intelligent recommendations.
